证书管理
回归简单。

为 strongSwan IKEv2 准备的轻量证书管理工具。一个 CLI，一个可选的只读 Web 面板，一条受控的 root helper 写边界。

Web 面板 默认只读 写操作由 root helper 白名单执行

WHY NECA

把证书生命周期收进一个工具

不引入第二份状态存储，不把 CA 私钥交给 Web 进程。

⌘

一条命令完成签发

issue / reissue / revoke / unrevoke / delete，覆盖证书、平台包与 CRL。

◐

默认只读的 Web

查看证书、验证 p12、受保护下载；需要写时再显式开启 helper。

⌁

清晰的权限边界

Web 容器非 root，无 ca.key、无 docker.sock；写操作只走 Unix socket 白名单。

↻

为运维而设计

JSON 配置、审计日志、SIGHUP 热重载、可持久化的 requestId 幂等缓存。

QUICK START

从容器到第一张证书

固定版本标签，先 dry-run，再签发。生产环境通过 OpenSSH 本地转发访问 Web。
